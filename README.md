# Gemma's Little Creations

Static HTML, CSS and JavaScript catalog for GitHub Pages. No backend, database, or account system is used.

## Publish
1. Upload all project files and the `images/` folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.

## Add a new creation
1. Open `admin.html` in your browser (or `your-site-url/admin.html`).
2. Enter the name, category, description, optional price, and choose a photo.
3. Click **Add to product list**.
4. Click **Download updated products.js**.
5. Click **Download new photos** and allow multiple downloads if your browser asks.
6. Replace `products.js` in GitHub with the downloaded file. Upload the new photo(s) into the repository's `images/` folder.
7. Commit changes. GitHub Pages will publish the update.

The product manager generates files in your browser; it does not automatically write to GitHub or synchronize across devices. The exported catalog and photos must be uploaded to the repository. The manager page is public if deployed, so it is not a secure admin login.
